# KestrelVL-7B model card (bootstrap)

KestrelVL-7B is an unfinished research model implementation. The code is
licensed AGPL-3.0-or-later; upstream weights and datasets retain their own
licenses. This repository currently contains no trained Kestrel weights and
reports no benchmark score. It must not be represented as GPT-5.6-equivalent
or production-ready.

Intended use is research into parameter-efficient multimodal coding agents,
attention compression, and reproducible local/GCP training. Known risks are
incorrect code, hallucinated tool use, data-license violations, benchmark
contamination, and unsupported long-context claims. Run the held-out gates and
review tool actions before use.
